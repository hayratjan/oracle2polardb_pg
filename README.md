# Oracle到PolarDB迁移工具

## 项目介绍

Oracle到PolarDB迁移工具是一个专业的数据库迁移解决方案，旨在帮助企业高效、安全地将Oracle数据库迁移到阿里云PolarDB PostgreSQL数据库。

## 核心功能

- **数据结构迁移**：自动转换表、视图、物化视图和存储过程
- **数据迁移**：高效同步数据，支持增量迁移
- **兼容性检查**：自动识别并解决Oracle与PostgreSQL之间的语法差异
- **迁移监控**：实时监控迁移进度和状态
- **错误诊断**：提供详细的错误报告和修复建议

## 使用流程

1. 配置Oracle源数据库连接
2. 配置PolarDB目标数据库连接
3. 选择需要迁移的对象
4. 创建迁移任务
5. 启动迁移并监控进度

## 技术特点

- 基于Django框架开发
- 支持多任务并行处理
- 使用SimpleUI美化管理界面
- 提供RESTful API接口
- 支持断点续传

## 系统要求

- Python 3.6+
- Oracle客户端库
- PostgreSQL客户端库
