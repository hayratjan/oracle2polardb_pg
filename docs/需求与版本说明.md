# 需求与版本说明

## 项目背景

本项目用于将 **Oracle 11g** 数据与对象迁移到 **PolarDB-PG（PostgreSQL 15 兼容）**，提供 Web 化配置、任务编排与监控能力。

## 适用版本

| 项目 | 说明 |
|------|------|
| **源端** | Oracle Database 11g 及更高版本。典型如：Oracle Database 11g Enterprise Edition Release 11.2.0.4.0 - 64bit Production（含 Partitioning、OLAP、Data Mining、RAT 等选件） |
| **目标端** | 阿里云 PolarDB PostgreSQL 或兼容 PostgreSQL 15 的实例 |

## 技术栈

- **Python**: 3.12
- **后端**: Django 5.2、Django REST framework、Django-SimpleUI（可选管理后台）
- **前端**: Vue 3、TypeScript、Vite、Bootstrap 5
- **数据库驱动**: cx_Oracle（Oracle）、psycopg2（PostgreSQL）

## 主要迁移能力

- **表 (Table)**：表结构及全量数据迁移
- **物化视图 (Materialized View)**：物化视图定义及刷新逻辑
- **视图 (View)**：视图定义迁移（含常见 Oracle 语法转换）
- **例程 (Routine)**：存储过程、函数等，含基础语法转换（如 NVL→COALESCE）
- **视图数据迁移到表**：将视图查询结果物化到目标表
- **所有表**：按 Schema 批量建表迁移任务
- **视图数据迁移到 SQLite**：导出为本地 SQLite 文件，便于归档或离线分析

更多功能与使用方式见根目录 [README.md](../README.md) 的「核心功能」与「功能说明」。
