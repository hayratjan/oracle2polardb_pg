# 桌面客户端构建与打包指南

Oracle2PolarDB 迁移工具基于 **Tauri 2** 构建跨平台桌面客户端,一次开发,三平台分发(Windows / macOS / Linux)。

## 架构概览

```
┌─────────────────────────────────────────────┐
│  Tauri 窗口 (WebView)                        │
│  ┌───────────────────────────────────────┐  │
│  │  Vue 3 前端 (frontend/dist)            │  │
│  │  - 路由 / 视图 / 主题 / 启动遮罩        │  │
│  └─────────────────┬─────────────────────┘  │
│                    │ invoke()                 │
│  ┌─────────────────▼─────────────────────┐  │
│  │  Rust 后端 (src-tauri)                 │  │
│  │  - start_backend / stop_backend        │  │
│  │  - backend_status / system_info        │  │
│  └─────────────────┬─────────────────────┘  │
│                    │ spawn()                  │
│  ┌─────────────────▼─────────────────────┐  │
│  │  Django 后端 (resources/backend/)      │  │
│  │  - 监听 127.0.0.1:8000                 │  │
│  │  - SQLite 本地数据库                    │  │
│  └───────────────────────────────────────┘  │
└─────────────────────────────────────────────┘
```

## 前置依赖

### 通用
- Rust 1.77+: https://rustup.rs
- tauri-cli 2.x: `cargo install tauri-cli --version "^2.0.0" --locked`
- Node.js 20+, pnpm 9+
- Python 3.12+(用户机器也需要)

### macOS
```bash
xcode-select --install
```

### Linux (Debian/Ubuntu)
```bash
sudo apt install -y libwebkit2gtk-4.1-dev libgtk-3-dev \
  libayatana-appindicator3-dev librsvg2-dev libssl-dev patchelf rsync
```

### Windows
- Visual Studio 2022 或 Build Tools(含 C++ 桌面开发工作负载)
- WebView2 Runtime(Windows 10/11 通常预装)

## 开发模式

```bash
# 1. 启动 Django 后端
./start_dev.sh

# 2. 启动 Tauri 开发窗口(另开终端)
cd src-tauri && cargo tauri dev
```

## 本地构建

### 一键脚本
```bash
# macOS / Linux
chmod +x scripts/build-desktop.sh
./scripts/build-desktop.sh

# Windows (PowerShell)
.\scripts\build-desktop.ps1
```

### 高级选项
```bash
# Debug 构建
./scripts/build-desktop.sh --debug

# macOS 通用二进制
./scripts/build-desktop.sh --target universal-apple-darwin --bundles dmg

# Linux 仅 AppImage
./scripts/build-desktop.sh --bundles appimage
```

## CI/CD 自动构建

推送 `v*` 标签自动构建三平台并发布 GitHub Release:
```bash
git tag v2.5.0
git push origin v2.5.0
```

## 常见问题

### 找不到 manage.py
构建脚本会自动复制后端代码到 `src-tauri/resources/backend/`。手动构建时需参考脚本步骤。

### macOS 提示「无法验证开发者」
未签名应用限制。用户侧: `xattr -cr /Applications/Oracle2PolarDB\ 迁移工具.app`

### Linux 缺少 libwebkit2gtk-4.1
```bash
sudo apt install libwebkit2gtk-4.1-0
```

### 前端白屏
检查 `vite.config.ts` 的 `base` 配置,Tauri 模式必须为 `'./'`。
