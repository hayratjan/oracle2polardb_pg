概述

Oracle到PolarDB-PG迁移平台

本平台提供了从Oracle数据库迁移到PolarDB-PG的完整解决方案。支持以下功能：

  • 表结构和数据迁移
  • 视图迁移
  • 物化视图迁移
  • 存储过程和函数迁移
  • 批量迁移功能
快速开始

基本步骤

  1. 配置源Oracle数据库连接
  2. 配置目标PolarDB-PG数据库连接
  3. 创建迁移任务
  4. 执行迁移
  5. 验证迁移结果
数据库连接

Oracle数据库连接

配置Oracle数据库连接需要以下信息：

  • 主机名或IP地址
  • 端口号（默认1521）
  • 服务名
  • 用户名
  • 密码

PolarDB-PG数据库连接

配置PolarDB-PG数据库连接需要以下信息：

  • 主机名或IP地址
  • 端口号（默认5432）
  • 数据库名
  • 用户名
  • 密码
迁移任务

支持的迁移类型

迁移类型 说明
表迁移 迁移表结构和数据，包括主键、索引等
视图迁移 转换并迁移视图定义
物化视图迁移 转换并迁移物化视图定义和数据
存储过程迁移 转换并迁移PL/SQL存储过程
批量迁移 批量迁移指定schema下的所有表
故障排除

常见问题处理

  1. 检查网络连接是否正常
  2. 验证数据库服务是否运行
  3. 确认连接信息是否正确
  4. 检查防火墙设置

  1. 查看任务日志了解具体错误信息
  2. 检查源表和目标表的权限设置
  3. 验证数据类型映射是否正确
  4. 确认目标数据库空间是否充足
常见问题

本平台支持Oracle 11g及以上版本。

对于大表迁移，平台采用分批处理策略，每批处理固定数量的数据，以避免内存溢出。同时，您可以通过监控页面查看迁移进度。
